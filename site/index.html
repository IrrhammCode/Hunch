Swipe UP or DOWN. 60-second markets on Monad.

One gesture on iOS. Privy email OTP creates an embedded wallet; that wallet is the onchain trader. Pyth prices every 60s BTC/USD round on Monad testnet.

GitHub Try path Submit write-up Video script

How it works

  1. 01Email OTP via Privy — embedded Ethereum wallet on Monad.
  2. 02Fund testnet AUSD + MON (capped faucet).
  3. 03Swipe UP or DOWN on the live 60s round. Wallet signs commitBuy.
  4. 04API relays executeBuy after delay-blocks with a fresh Pyth price.
  5. 05Keeper resolves → claim in BOOK → open the tx on MonadVision.
