## Synthesis — top IA patterns + MVP set

### Top IA patterns (2024–2026)

1. **Bottom tabs ~4–6:** Home/Portfolio · Markets/Explore · Trade/Swap · Spend/Cash · Predict (optional) · Earn/Lend (optional). Jupiter changelogs name Home, Markets, Trade, Portfolio, Spend, Predict explicitly; Phantom ships Home + Explore + Predict + Cash + +Trade; Backpack tabs Markets / Trade (spot+perps) / Wallet / Earn / Stocks.

2. **Markets ≠ Swap ≠ Perps ≠ Predictions:** Markets = discovery lists (trending, filter by chain/category); Swap = token pair form with quote + confirm; Perps = market picker + long/short ticket + positions; Predictions = Yes/No spend ticket + cash out. All write into one portfolio/positions surface.

3. **Chain as leg-level context, not app-level mode:** Unified multi-chain portfolio; chain filter chips on Markets/Explore; network selector on You Pay / You Receive; cross-chain = swap/bridge; same-ticker assets grouped with cumulative balance.

4. **First session:** email/Apple ID → fund (Apple Pay / card / Cash) → trade. Seed phrases optional/secondary. Gas hidden when paying from Cash/stable.

5. **Progressive disclosure:** defaults hide slippage/fees/bridges; advanced (limit, leverage, SL/TP, subaccounts) behind sheets or pro modes.

### Minimum feature set for a demo-worthy mobile multichain trading app (≈3 weeks)

- **Wallet core:** create/import (email or seed), multi-chain balances grouped by ticker, asset detail with price + 24h stats.
- **Markets tab:** trending list + search + chain filter + market overview (price/volume/mcap).
- **Trade/Swap:** pair picker, You Pay/You Receive with **network selector**, quote (mock or 1 aggregator), confirm sheet showing fees/impact, tx history.
- **Portfolio/Positions:** holdings + open positions (even if only swaps seeded).
- **First-session:** 3-step onboarding (create → fund mock/sandbox → trade) + one fiat or testnet fund path.
- **Chain switcher pattern:** filter chips + leg-level network pickers + “unified balance” — not a global chain modal gate.
- **Optional wow-layer (if time):** one Yes/No prediction card or one long/short perps ticket backed by mock/external liquidity — matches Phantom’s “wallet + trade + predictions” narrative without full enterprise stack.

**Defer for enterprise:** margin engine, subaccounts, stocks/RWA, cards, lending, social chat, multi-jurisdiction KYC, hardware wallets, tax export, desktop terminal, full multi-bridge ops.
