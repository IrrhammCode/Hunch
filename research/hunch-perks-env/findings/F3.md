## 3. Best endpoints for Hunch portfolio

### Claim: Two wallet endpoints cover PORTFOLIO/YOU — summary totals + priced token list. Base URL `https://api.zerion.io`.

#### A) Get wallet portfolio (hero total + 24h + by-chain)

**Quote:** “Get wallet portfolio — A wallet's total portfolio value, broken down by chain and position type.” Path: `GET /v1/wallets/{address}/portfolio`. “Returns the portfolio overview of a wallet, with the total value broken down by chain and by position type.” `filter[positions]` defaults to `only_simple` (wallet tokens; excludes DeFi unless `no_filter`). Response attributes: `positions_distribution_by_type`, `positions_distribution_by_chain`, `total.positions`, `changes.absolute_1d`, `changes.percent_1d`. Optional `currency` (default `usd`).

**URL:** https://developers.zerion.io/api-reference/wallets/get-wallet-portfolio  
**Date:** 2026-09-18  
**Confidence:** High

**Recommended proxy call (matches Hunch today):**

`GET https://api.zerion.io/v1/wallets/{address}/portfolio?currency=usd&filter[positions]=only_simple`

#### B) Get wallet fungible positions (token rows)

**Quote:** “Get wallet fungible positions — A wallet's token balances and DeFi positions across every supported chain, priced and ready to render.” Path: `GET /v1/wallets/{address}/positions/` (trailing slash in OpenAPI). “Returns the fungible positions of a wallet: tokens and native coins held directly, plus DeFi protocol positions when `filter[positions]` is set to `only_complex` or `no_filter`.” Filters: `filter[chain_ids]`, `filter[position_types]`, `filter[trash]` (default `only_non_trash`), `sort` (`value` / `-value`). “Not paginated. All matching positions come back in a single response” per OpenAPI notes (schema docs); recipes still show `links.next` for some list patterns — treat Hunch 12-token slice as UI-safe.

**URL:** https://developers.zerion.io/api-reference/wallets/get-wallet-fungible-positions  
**Date:** 2026-09-18  
**Confidence:** High

**Recommended proxy call:**

`GET https://api.zerion.io/v1/wallets/{address}/positions/?currency=usd&filter[positions]=only_simple&sort=-value`

**Recipe pairing:** “A single call to the portfolio endpoint returns the wallet's total value, chain distribution, and 24h change.” Positions recipe: “Fetch individual positions sorted by value. Use `filter[trash]=only_non_trash` to exclude spam tokens.” Env sample: `const API_KEY = process.env.ZERION_API_KEY;` + `authorization: \`Basic ${btoa(API_KEY + ":")}\``.

**URL:** https://developers.zerion.io/recipes/multi-chain-portfolio  
**Date:** 2026-09-18  
**Confidence:** High

Optional later: `GET /v1/wallets/{address}/charts/{period}` for YOU balance sparkline (`day|week|month|…`).
