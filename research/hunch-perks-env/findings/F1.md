### Interpretation for Hunch (Med)

| Surface | Dedicated QN Build endpoint | Public `testnet-rpc.monad.xyz` |
|---|---|---|
| Plan/account RPS | **50 rps** (Build) | Documented **50 rps** (25 rps on eth_call / eth_estimateGas) |
| Auth | Unique token path (private) | Public URL, shared |
| Contention | Your quota + dashboard isolation | Shared public pool; observed 429s still possible under load |
| Credits | 80M/mo @ 30 credits/call ≈ **~2.67M Monad calls/mo** theoretical | N/A (not metered to you) |
| Logs/metrics | Build+ endpoint Metrics/Error Logs | None for you |
| Streams / Webhooks | Included on Build | N/A |

**Practical takeaway:** Official public testnet is no longer the “15 rps” figure in older Hunch comments — docs say **50 rps / 25 rps for eth_call**. The perk’s real win for a hackathon is **dedicated credentials, isolation, dashboard proof of Quicknode usage, Build security controls, and Streams/Webhooks headroom** — not a massive RPS jump vs the current public QuickNode-backed URL. Still claim + paste it: judges expect `MONAD_RPC_URL` to be Quicknode, and private endpoints avoid public-pool flakiness during demos.

## F. Pitfalls (Hunch-specific)

| # | Pitfall | Evidence | Impact | Fix | Confidence |
|---|---|---|---|---|---|
| **P1** | **Detection bug:** real Quicknode host is `quiknode.pro` (no “ck”), but Hunch checks `quicknode.com` / `quicknode` | `isQuicknodeRpc` = `/quicknode\.com/i` in `src/shared/sponsors.ts`; doctor = `/quicknode/i` in `scripts/doctor.ts` L117; official URLs `*.quiknode.pro/*` | After pasting a real perk URL, doctor prints **“custom endpoint set”** not “Quicknode (perk)”; `/v1/sponsors/status` shows `quicknode: "custom-rpc"` not `"configured"` — **false negative on the perk checklist** | Change regex to `/quiknode\.pro\|quicknode/i` in `sponsors.ts` + `doctor.ts` | High |
| **P2** | Create **Mainnet (143)** instead of **Testnet (10143)** | QN docs list both networks; Hunch contracts/deployments are testnet | Wrong chainId → Hardhat/ethers fail `"Wrong network"`; keeper writes nowhere useful | Select **Monad Testnet**; verify `eth_chainId` = `0x279f` | High |
| **P3** | Auth token is the full path secret | Token auth default; `"You can regenerate tokens anytime… old tokens become invalid immediately"` | Committing `.env` or putting `EXPO_PUBLIC_MONAD_RPC_URL` in public EAS builds leaks a billed endpoint | Never commit `.env`; prefer server-side RPC for phone; rotate if leaked | High |
| **P4** | Hunch rate-limit detector misses Quicknode codes | `rpcRetry.ts` matches `rate limit\|too many requests\|limited to \d+/sec\|-32090\|-32011` — **not** `-32007` / `-32008` / HTTP 429 body from QN errors doc | Soft-retry may not trigger on Build-plan overage; demo can fail hard | Add `-32007\|-32008\|429` to `isRateLimit` | High |
| **P5** | Stale “15 rps public” assumption | Official testnet table: **50 rps** (25 rps eth_call/estimateGas) as of 2026-09-18 | Docs/PERKS/keeper comments overstate public fragility; may over-throttle after perk is live | Update comments after claim; keep retry as safety net | High |
| **P6** | `.env.example` docs URL host | Comment says `https://docs.quicknode.com/docs/monad` | May 404; agents/devs copy wrong host | Canonical docs: **https://www.quicknode.com/docs/monad** (llms.txt at `/docs/monad/llms.txt`) | High |
| **P7** | `eth_getLogs` / historical `eth_call` limits still apply on paid RPC | QN errors: logs/filter **10,000 block range** cap; Monad public QuickNode getLogs **100 blocks** (mainnet table); pruned >40k recent | Indexer lookback that “melts public RPC” can still 413/-32602 on QN | Keep small log windows (repo already does); don’t assume archive = unlimited range | High |
| **P8** | Credit burn vs RPS | Monad = **30 credits/call**; Build 80M/mo | Heavy debug_trace* (2×) or large calls (4×) can hit overage $0.62/1M faster than RPS | Prefer HTTP eth_call/eth_getLogs; avoid debug_trace in hot loops | Med |
| **P9** | Speculative `"latest"` on Monad | `"latest"` = Proposed; pending tag ≈ latest; tx hash lookups can be null until included | Keeper that treats latest as final may race reorgs/abandoned proposals | For settlement reads use `"finalized"` / `"safe"` where stakes matter | High |
| **P10** | Mobile embeds token in app binary if `EXPO_PUBLIC_*` set | Expo public env is compiled into JS bundle | Token visible to anyone with the IPA/APK | Optional for demo; production should proxy via Hono API | High |
| **P11** | Multi-token / disable auth misconfig | Security docs allow disabling token auth (public endpoint) | Unsecured endpoint burns Build credits | Leave token auth **on**; use header `x-token` only if splitting secrets | High |
| **P12** | Plan expiry after 3 mo | Metropolis perk = Build **3 months** | After expiry RPS/credits drop or endpoint 403 (`Endpoint Disabled`) | Calendar reminder; keep public fallback in `.env.example` comments | Med |
